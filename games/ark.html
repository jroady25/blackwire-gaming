Rules for this cluster

Everything in the network-wide community rules applies here, plus what's specific to a no-wipe PvE map:

  • Offline raid protection and build-limit specifics are pinned in the ARK Discord channel — check there before setting up a base near other tribes.
  • No blocking resource nodes, obelisks, or transfer terminals — that counts as griefing on a PvE server.
  • Server-specific settings (rates, difficulty, etc.) are listed per-server in the channel, since they can differ map to map on the same cluster.

Cluster transfers

This cluster supports transferring survivors, dinos, and items between linked maps. See the field manual's transfer section for how it works — which specific maps are currently linked is kept current in the Discord channel, since that can change as maps are added.
