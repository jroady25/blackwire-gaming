01 · getting_started

Getting started.

Four things happen in order, and skipping one just means doing it later anyway:

  1. Join the Discord. See Sign In — this is where verification, whitelisting, and every game channel live.
  2. Verify and read the pinned rules in your game's channel — the general rules on this page apply everywhere, but each game channel pins anything specific to it.
  3. Grab connect info from that channel: server IP, current map or world, and whether a whitelist request is needed.
  4. Launch and connect. If a mod list applies to your game, install it first — see Mod & Client Setup below.
02 · community_rules

Community rules.

The standard every BlackWire server holds, regardless of game.

  • No cheating, exploiting, or duping. Using a bug for advantage is the same as cheating — report it instead.
  • No griefing on PvE servers. Building to intentionally block, wall in, or grief other players' access is a bannable offense.
  • Respect staff decisions. Disagree in a ticket, not in general chat. Staff time is volunteer time — treat it that way.
  • Keep it civil. No harassment, hate speech, or targeted personal attacks, in game or in Discord.
  • Follow the per-game addendum. Build limits, PvP windows, taming rates, and similar specifics live in each game's channel and landing page.
Note

This is the short version. The full rules document lives in the Discord's #rules channel and is the one staff actually enforce against — read it there before you play.

03 · mod_and_client_setup

Mod & client setup.

Mods vary by game and sometimes by server — always check the pinned mod list before connecting.

Where a server runs mods, its Discord channel pins the exact list and load order. A mismatched mod list is the single most common reason a client can't connect — check version numbers match, not just names, before opening a support ticket.

Games running through Steam Workshop subscribe automatically on next launch once you're in the right in-game session; games with manual mod installs will have download links pinned alongside the list.

04 · cluster_transfers

Cluster transfers.

ARK: Survival Ascended only — this mechanic doesn't apply to every game on the network.

ARK's cluster lets you move survivors, dinos, and items between maps in the same cluster group. Not every server pair is linked — check the ARK page for which maps currently share a cluster before you plan a transfer.

  • Obelisks and Terminals both work for cluster transfer, and drop-offs are held for a limited window.
  • Transferring into a full server queues you — patience beats spamming the terminal.
  • PvP-flagged maps have extra transfer restrictions during active raid windows; see that server's channel.
