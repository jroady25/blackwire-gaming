BlackWire Admin.

A full in-game admin panel for ARK server staff, built for controller as well as mouse and keyboard. Only the server owner and staff with a role can open it.

Get it on CurseForge Full guideServer settingsHelp on Discord
Works onPC · Xbox · PlayStation

CategoryServer & Admin
SetupNone needed
01 · what_it_does

What it does.

  • Players and tribes: heal, teleport, freeze, watch, ban, edit inventories and manage whole tribes.
  • Spawning: any creature or item, mod items included, plus bosses and titans.
  • Live map, Admin Gun, zones, broadcasts, polls, XP events and scheduled jobs.
  • Paint creatures: pick colours when you spawn one, or shoot any creature with the Admin Gun to change its colours, stats and name. The gun can also give random colours, make a female lay an egg and cure cryo sickness.
  • Staff roles with their own permission switches, an action log with undo, and cheat and fake-admin alerts.
  • Base tools: browse every base, find dupes and the busiest tribes, and clean up bases nobody visits.
  • Discord link: cross-server chat, a staff log, /blackwire commands and one ban list for all servers.
02 · full_guide

How it works.

Everything is set in game, from the panel. There is no INI.

Opening it

Hold Reload (PC: R, Xbox: X, PlayStation: Square) and pick BlackWire Admin. Only the server owner and staff with a role see it.

The pages

The pages run down the left side of the panel, each with its own icon.

PlayersRolesSpawnScanTribesServerCommandsLogReportsMy tools

Players and tribes

Pick a player to heal, teleport, freeze, watch, ban or edit their inventory. Whole tribes can be managed in one go.

Spawning

Any creature or item, mod ones included, plus bosses and titans. Pick a creature's colours before it spawns.

The Admin Gun

Shoot a creature to change its colours, stats and name, give it random colours, make a female lay an egg or cure cryo sickness.

Staff roles

Give staff a role, and each role gets its own permission switches.

Action log

Every admin action is logged with undo, including commands run from the Commands page. Cheat and fake-admin alerts show up here.

Base tools

Browse every base, find dupes and the busiest tribes, and clean up bases nobody visits.

Server tools

A live map, zones, broadcasts, polls, XP events and scheduled jobs.

Discord link

Cross-server chat, a staff log, /blackwire commands and one ban list for all your servers.
