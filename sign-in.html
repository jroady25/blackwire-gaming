Access runs through Discord.

BlackWire doesn't run its own account system — your Discord identity is your BlackWire identity. Join the server, verify, and you're whitelisted on whichever game you're playing.

Steps to get connected

  1. 1

    Join the Discord

    This is the front door for every game on the network — announcements, rules, live support, and where whitelisting happens.

  2. 2

    Read the rules, then verify

    A short read in the #rules channel, then react or run the verify command to unlock the rest of the server.

  3. 3

    Pick your game's channel

    Each game has its own channel with connect info, current map/server list, and a request to get whitelisted if the game needs it.
